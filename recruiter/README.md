# Recruiter Portal

A comprehensive recruitment platform integrated with the Octamy certification system.

## Features

- **Multi-step Registration**: Wizard-based onboarding with individual info, company details, and KYC documents
- **Credit System**: Pay-per-access model for profile views, CV downloads, and interview data
- **Advanced Search**: Filter candidates by technology, location, experience, availability, etc.
- **Profile Management**: View candidate certifications, interview scores, and CVs
- **Dashboard**: Overview of credits, recent activities, and KYC status

## Credit System

- Profile View: 1 credit
- CV Access/Download: 1 credit  
- Interview Data Access: 2 credits

## Tech Stack

- React + TypeScript
- Tailwind CSS with Poppins font
- Same authentication pattern as main app
- Separate database schema for recruiters

## Getting Started

All recruiter routes are prefixed with `/recruiter`
